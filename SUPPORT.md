# Support Guidelines

Thank you for being part of the **Google Developer Groups on Campus (GDGoC) - SATI Vidisha** community! We are committed to providing prompt, helpful, and community-driven support for our official website, technical projects, and developer activities.

---

## 🧭 How to Get Support

Depending on what you need assistance with, please use the appropriate channel below:

### 1. Technical Issues & Bug Reports
If you encounter a bug, unexpected UI glitch, or performance issue on the website:
- **Search Existing Issues**: Check our [GitHub Issues](https://github.com/GDGoC-SATI/website/issues) to see if the problem has already been reported.
- **Open a New Issue**: If it has not been reported, open a new issue using our issue template. Please include:
  - Clear summary of the issue
  - Steps to reproduce
  - Expected vs actual behavior
  - Device, browser, and OS version
  - Screenshots or console logs if applicable

### 2. Feature Requests & Enhancement Ideas
Have an idea for a new section, integration, or improvement?
- Submit a proposal via [GitHub Issues](https://github.com/GDGoC-SATI/website/issues) tagged with `enhancement`.
- Discuss ideas with fellow developers on [GitHub Discussions](https://github.com/GDGoC-SATI/website/discussions).

### 3. Events, Hackathons & Community Participation
For questions regarding chapter activities, upcoming workshops, study jams, and hackathons:
